# 政治ダッシュボード（フレンド用）

政治が苦手な人向けの、やさしい政治ダッシュボードです。

- 公開ページ: https://emitirushia-pixel.github.io/politics-dashboard/
- スマホのブラウザで開いて「ホーム画面に追加」すると、アプリのように使えます。

## これは何？

「今週の政治、3行で」の要約、次の選挙までのカウントダウン、そして暮らしに近い順の5テーマ（暮らしとお金／国会・法案／意見・申請の締切／選挙／世論調査）で、開催中の制度変更・法案・締切・選挙・世論調査を、やさしい言葉で並べたページです。各項目には「なんで大事？」「決まるとどう変わる？」、用語の解説、出典リンクが付いています。

## 夜間自動更新の仕組み

- 毎晩、GitHub Actions（`.github/workflows/nightly.yml`）が 05:37（日本時間）に自動で動き、予備として 08:37 にももう一度試します。
- `update.py` が公開情報源（e-Gov パブリックコメントの公式RSS、衆議院の議案一覧など）を取得し、Gemini API でやさしく要約し直して `data.json` を更新します。取得や検証に失敗したテーマは、前回の内容をそのまま残すので、ページが壊れたり空になったりはしません。
- 要約にはリポジトリの Secrets に登録した `GEMINI_API_KEY` を使います。**このキーが未登録の間は、夜間ジョブ自体は毎晩動きますが、要約をスキップして `data.json` を変更しません**（ページは初回公開時点の内容のまま表示されます）。
- 使うキーは、Discord Bot のキーとは別の、新しい Google プロジェクトで作る専用キーです。登録はオーナー本人が下の手順で行います。
- ページ本体（`index.html`）は `data.json` を読み込んで表示するだけの静的サイトで、GitHub Pages から配信されています。

## オーナーがやること

- たまにページを開いて、上部の「最終更新」の日付が最近の日付になっているか見るだけでOKです。
- **2日以上「最終更新」が古いまま止まっていたら**、更新のどこかで問題が起きている合図です。そのときはエージェント（Muse）に連絡してください。
- 要約を有効にするには、`GEMINI_API_KEY` の登録が必要です（手順は次の節）。未登録の間は、夜間ジョブは動いても要約をスキップするので、内容は変わりません。

## GEMINI_API_KEY の登録手順（スマホのブラウザでOK）

Discord Bot のキーとは枠を分けるため、**新しい Google プロジェクトで作った新しい Gemini API キー**を使います。キーを作ったら、GitHub の画面でオーナー本人が登録してください。

1. このリポジトリのページ（https://github.com/emitirushia-pixel/politics-dashboard）を開く
2. 上部の **Settings**（設定）をタップ（見当たらない場合は右端の「…」の中にあります）
3. 左メニューの **Secrets and variables** → **Actions** をタップ
4. **New repository secret** ボタンをタップ
5. **Name** に `GEMINI_API_KEY` と入力（半角英字、そのままコピー推奨）
6. **Secret** の欄に、新しく作った Gemini API キーを貼り付ける
7. **Add secret** ボタンをタップして完了

登録した次の夜の自動更新から、要約が有効になります。キーの中身は GitHub 上でも登録後は表示されません。

## ファイル構成

- `index.html` — ページ本体（スマホ向けアプリ風レイアウト、下部タブ：ホーム／日付順／テーマ別）
- `data.json` — 表示する全データ（夜間自動更新の対象）
- `update.py` — 夜間更新スクリプト（Python + requests）
- `manifest.json` / `icons/` / `sw.js` — ホーム画面追加（PWA）用。HTML と data.json は network-first で取得するので、古い内容が表示され続けることはありません
